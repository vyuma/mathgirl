# 確率の基本

## 確率の定義

ある試行において、起こりうるすべての場合の数を $N$、事象 $A$ が起こる場合の数を $n$ とすると、事象 $A$ の確率 $P(A)$ は、

$$P(A) = \frac{n}{N}$$

で定義されます。

## 確率の基本性質

1. $0 \leq P(A) \leq 1$
2. 全事象の確率: $P(\Omega) = 1$
3. 空事象の確率: $P(\emptyset) = 0$
4. 余事象: $P(\bar{A}) = 1 - P(A)$

## 加法定理

$$P(A \cup B) = P(A) + P(B) - P(A \cap B)$$

$A$ と $B$ が互いに排反（$A \cap B = \emptyset$）のとき：
$$P(A \cup B) = P(A) + P(B)$$

## 例題

### 例1
サイコロを1回振るとき、3以下の目が出る確率を求めなさい。

**解法：**
全事象 $N = 6$（1, 2, 3, 4, 5, 6）
3以下の目: $n = 3$（1, 2, 3）

$$P = \frac{3}{6} = \frac{1}{2}$$

### 例2
トランプ52枚から1枚引くとき、ハートまたは絵札を引く確率を求めなさい。

**解法：**
- ハート: 13枚
- 絵札（J, Q, K）: 12枚
- ハートかつ絵札: 3枚

$$P = \frac{13 + 12 - 3}{52} = \frac{22}{52} = \frac{11}{26}$$
