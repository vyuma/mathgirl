# 教材コンテンツ作成ガイド

このディレクトリには、大学受験数学（数I・A / 数II・B）の教材 Markdown ファイルを格納します。

## ディレクトリ構造

```
content/
├── math-1/          # 数学I
├── math-a/          # 数学A
├── math-2/          # 数学II
└── math-b/          # 数学B
```

各科目の下に `XX-slug/` 形式でユニット（単元）ディレクトリを作成し、その中に個別のトピックファイルを配置します。

### 命名規則

- **ディレクトリ**: `XX-slug/` — `XX` は2桁の連番、`slug` は英語のケバブケース
  - 例: `01-numbers-expressions/`, `03-quadratic-functions/`
- **ファイル**: `XX-slug.md` — ディレクトリと同じ規則
  - 例: `01-expansion.md`, `02-factoring.md`
- 連番はソート順を制御するためのもの。途中の番号が空いても問題ありません

## Frontmatter（メタデータ）

各 Markdown ファイルの先頭に YAML frontmatter を記述します。

```yaml
---
title: "展開の公式"              # 表示用タイトル（日本語）
subject: "数学I"                 # 科目名: 数学I / 数学A / 数学II / 数学B
unit: "数と式"                   # 単元名（日本語）
topic: "展開と因数分解"          # トピック名（日本語）
difficulty: "基礎"               # 難易度: 基礎 / 標準 / 発展
prerequisites: []                # 前提となる他ファイルの相対パス（配列）
tags: ["展開", "乗法公式"]       # 検索用タグ（配列）
---
```

### フィールド説明

| フィールド | 必須 | 説明 |
|-----------|------|------|
| `title` | Yes | 教材のタイトル。日本語で簡潔に |
| `subject` | Yes | `数学I` / `数学A` / `数学II` / `数学B` のいずれか |
| `unit` | Yes | 学習指導要領に基づく単元名 |
| `topic` | Yes | 単元内のより細かいトピック名 |
| `difficulty` | Yes | `基礎`: 教科書レベル / `標準`: 入試標準レベル / `発展`: 難関大レベル |
| `prerequisites` | No | この教材を学ぶ前に理解しておくべき教材の相対パス |
| `tags` | No | 検索やフィルタリング用のキーワード |

## 本文の構成

以下のセクション構成を推奨します（必須ではない）:

```markdown
# タイトル

## 導入
なぜこの単元を学ぶのか、動機付けや背景

## 基本事項
定義・公式・定理の説明

## 例題
### 例題1
**問題**: ...
**解説**: ステップごとの詳しい解法

## つまずきやすいポイント
よくある間違いや注意点

## まとめ
要点の箇条書き
```

## 数式の書き方

LaTeX 記法を使用します。

### インライン数式

テキスト中に `$...$` で記述します。

```markdown
2次関数 $y = ax^2 + bx + c$ のグラフは放物線です。
```

### ブロック数式

独立した数式は `$$...$$` で記述します。

```markdown
$$
x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}
$$
```

### 数式記述の注意点

- `$$` の前後は空行を入れる
- 分数は `\frac{分子}{分母}`
- 添え字: 下付き `a_n`、上付き `a^2`
- ベクトル: `\vec{a}` または `\boldsymbol{a}`
- 場合分け: `\begin{cases}...\end{cases}`
- 整列: `\begin{aligned}...\end{aligned}`

## 難易度の基準

| 難易度 | 目安 |
|--------|------|
| **基礎** | 教科書の例題・練習問題レベル。定義の理解と基本的な計算 |
| **標準** | 共通テスト・中堅大入試レベル。複数の知識を組み合わせる問題 |
| **発展** | 難関大入試レベル。高度な思考力・論証力を要する問題 |

## 例題の書き方

- 1ファイルにつき2〜4題を目安とする
- **解説は省略しない**: 途中式・考え方をステップごとに丁寧に記述する
- 難易度順に並べる（易→難）
- 計算だけでなく「なぜその方法を使うのか」を説明する

## コンテンツ追加の手順

1. 適切なディレクトリにファイルを作成
2. frontmatter を記述
3. テンプレートに沿って本文を記述
4. 数式の `$` / `$$` の対応が正しいか確認
5. `prerequisites` に依存関係がある場合はパスを記述
