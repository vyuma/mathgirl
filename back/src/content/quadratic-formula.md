# 二次方程式の解の公式

## 基本形

二次方程式 $ax^2 + bx + c = 0$（$a \neq 0$）の解は、次の公式で求められます。

$$x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$$

## 判別式

$D = b^2 - 4ac$ を **判別式** と呼びます。

- $D > 0$ のとき：異なる2つの実数解
- $D = 0$ のとき：重解（1つの実数解）
- $D < 0$ のとき：実数解なし（虚数解）

## 例題

### 例1
$x^2 - 5x + 6 = 0$ を解きなさい。

**解法：**
$a = 1, b = -5, c = 6$ を公式に代入すると、

$$x = \frac{5 \pm \sqrt{25 - 24}}{2} = \frac{5 \pm 1}{2}$$

よって $x = 3$ または $x = 2$

### 例2
$2x^2 + 3x - 2 = 0$ を解きなさい。

**解法：**
$a = 2, b = 3, c = -2$ を公式に代入すると、

$$x = \frac{-3 \pm \sqrt{9 + 16}}{4} = \frac{-3 \pm 5}{4}$$

よって $x = \frac{1}{2}$ または $x = -2$
