## Frontend 機能

| 機能 | ファイル | 説明 |
|------|---------|------|
| **3Dアバター** | `VRMChat.tsx` | VRMモデル(alice.vrm)表示、口パク、瞬き、体揺れアニメーション |
| **音声認識** | `lib/stt/` | Web Speech API、日本語対応、無音検出で自動送信 |
| **WebSocket通信** | `lib/websocket/` | テキスト/音声のストリーミング受信 |
| **音声再生** | `lib/audio/` | Base64音声の順序付きストリーミング再生 |
| **TTS選択** | `lib/tts/useCoeiroink.ts` | COEIROINK スピーカー/スタイル選択 |

---

## Backend 機能

| 機能 | ファイル | 説明 |
|------|---------|------|
| **チャットWS** | `chat_ws.py` | WebSocket経由でリクエスト受信、テキスト+音声をストリーミング返却 |
| **AIエージェント** | `agent.py` | Gemini 2.5 Flash Lite、文単位ストリーミング生成 |
| **ストリーミングTTS** | `streaming_tts.py` | LLM出力を並列TTS変換、順序保証で配信 |
| **ターンテイキング** | `predictor.py` | VAPモデルで発話終了予測 (未使用?) |

---

## データフロー

```
1. ユーザー発話 → Web Speech API でテキスト化
2. 1.5秒無音検出 → 自動送信
3. WebSocket で chat_request 送信
4. AliceAgent が Gemini で文単位生成
5. 各文を並列で COEIROINK TTS 変換
6. TextChunk → AudioChunk を順序通りにストリーミング
7. フロント: テキスト表示 + 音声再生 + 口パク
```
